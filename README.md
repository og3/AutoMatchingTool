# AutoMatchingTool
求人サイトにおける求人票と登録しているユーザーの職務経歴書のマッチングを自動、あるいは省力化するツールです。
## ツールについて
このツールは、人材紹介業務における求人と登録人材の候補選定を効率化する、GoogleスプレッドシートとGASを使った自動マッチング支援ツールです。  
担当者が求人票を貼り付けて実行すると、記載された必須条件を読み取り、「経験職種」「経験業界」「スキル」の3項目に分類・タグ化します。同じ処理を人材DBに登録された職務経歴書にも行い、双方のタグを照合して、一致した項目や候補者ごとのマッチング率を表示します。  
条件に合う人材はメッセージ送信候補リストにまとめられるため、従来のように多数の職務経歴書を一件ずつ読み、検索語を変えながら探す手間を削減できます。  
なお、ツールだけで紹介可否を決めるのではなく、抽出された候補者を担当者が最終確認する設計です。表記揺れには職種・業界・スキルの辞書で対応し、検索語を追加することで継続的に精度を改善できます。

## 運用上の注意
本ツールはGASで運用しており、コードを変更する際は以下の手順でデプロイを行ってください。  
理由は、「新規デプロイ」を作るとURLが変わり、お客さんに案内している入力フォームのURLが変わってしまうためです。  
### 手順
1, GASエディタ右上の［デプロイ］→［デプロイを管理］を開く。  
2, Webアプリとして公開済みのデプロイを選び、［︙］→［編集］。  
3, 「バージョン」のところで新しいバージョンを作成（メッセージを入れて保存）。  
4, そのまま保存（＝既存デプロイを最新バージョンに差し替え）。  
→ この手順なら 同じ /exec のURLのまま、中身だけ更新されます。
